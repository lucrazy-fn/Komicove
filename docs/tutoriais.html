ANDROID / FIRST READ

Bring a comic to Android

Use a folder on your phone so Komicove can find your local comics.

  1. Download the official APK from this site and install it.
  2. Open Komicove and choose guest mode.
  3. In Library, tap Folders, then Add folder. Pick the folder with your comics and grant access.
  4. Wait for the scan and tap a cover to start reading.

You should see: your comic covers in the Android library.

02

WINDOWS / LINUX

Start on desktop

Add a local folder, then open your first comic from the library.

  1. Install or unpack the package for your computer and launch Komicove.
  2. Choose guest mode for local reading without an account.
  3. Use the library or Folders area to choose the folder with your comics.
  4. Select a cover and turn a few pages.

You should see: a cover in your library and saved reading progress.

READING / COMFORT

Set up your reading view

Try a layout that fits the comic and your screen. Controls differ between devices.

  1. Open a comic and reveal the reader controls.
  2. Try page direction and layout, such as single page, double page or manga order when available.
  3. Adjust fit and zoom. On Android, Reader preferences also offers brightness modes.
  4. Add a bookmark, leave the reader and reopen the comic.

You should see: a comfortable page layout and your reading point when you return.

LIBRARY / ORGANIZATION

Organize the collection

Use search, favorites and collections to make a growing library easier to navigate.

  1. Add a few local comics and search for one by title.
  2. Mark a favorite and place a title in a collection.
  3. Try sorting the library by the option that works best for you.
  4. On desktop, add a monitored folder if you keep new files in one location.

You should see: titles you can find quickly and a collection you can revisit.

05

DATA / SAFETY

Keep a backup

Save your reading data and keep your original comic files separately.

  1. On desktop, choose Backup in the sidebar. On Android, open Settings and choose Backup.
  2. Save the JSON file somewhere you can find again.
  3. Make a separate copy of your original comics. The JSON does not contain them.
  4. Use Restore on the same platform when you need that data back.

You should see: a saved JSON backup alongside your separate comic collection.

06

WHEN SOMETHING STOPS

Fix common problems

A short checklist before reporting a problem.

  1. If the library is empty, check the folder choice and access permission.
  2. If a file fails, check its format and try a standard CBZ. Some desktop archives need 7-Zip.
  3. If the issue remains, include your device, app version and steps to reproduce it in a GitHub issue.
