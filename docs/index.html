05 / ANTES DA PRIMEIRA PÁGINA

Ficou alguma
dúvida?

Preciso instalar Python?+

Não. Ao usar o instalador do PANEL, o Python e as dependências do leitor já estão incluídos.

Preciso de conta?+

Não para leitura local. Você pode usar o modo convidado para abrir e organizar seus próprios arquivos.

Funciona sem internet?+

A leitura de arquivos locais funciona sem servidor. Comunidade e sincronização precisam de internet e usam o servidor do PANEL, já configurado no aplicativo.

Preciso instalar 7-Zip?+

No Windows, sim, para os formatos que dependem dele. No Android, não é necessário instalar o 7-Zip.

Onde reportar bugs?+

Nas Issues do GitHub. Informe sua versão, os passos para reproduzir o erro e, se possível, uma captura de tela. Nunca compartilhe senhas ou tokens.
