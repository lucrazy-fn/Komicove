05 / ANTES DA PRIMEIRA PÁGINA

Ficou alguma
dúvida?

Preciso instalar Python?+

Não para usar o instalador Windows, os pacotes Linux ou o APK Android.

Preciso de conta?+

Não para leitura local. Você pode usar o modo convidado para abrir e organizar seus próprios arquivos.

Funciona sem internet?+

A leitura de arquivos locais funciona sem servidor. Comunidade e sincronização precisam de internet e usam o servidor do Komicove, já configurado no aplicativo.

Preciso instalar 7-Zip?+

No Windows e no pacote portátil Linux, alguns formatos dependem de uma ferramenta compatível, como 7-Zip. No Android, não é necessário instalar o 7-Zip. O Flatpak Linux pode ter limitações com esses formatos.

Onde reportar bugs?+

Nas Issues do GitHub. Informe sua versão, os passos para reproduzir o erro e, se possível, uma captura de tela. Nunca compartilhe senhas ou tokens.
