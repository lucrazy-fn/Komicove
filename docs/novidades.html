Translation is experimental

Results may contain missed text, OCR errors, inaccurate translations or visual imperfections. Your original comic is preserved, so review the result before exporting or sharing it.

OTHER CHANGES

Other changes in this release.

01

Library and performance

CBZ, ZIP and 7Z reading is improved, watched folders are more reliable and blocked state files are handled more safely.

02

Updates and notices

Komicove now handles multiple update sources, version history, team notices and matching downloads more clearly.

03

Site and support

The official site was redesigned with downloads, docs, tutorials, release history, older versions and clearer ways to support the project.

04

Stability across platforms

Authentication, synchronization, cover loading and interface responsiveness received fixes on Windows, Linux and Android.
