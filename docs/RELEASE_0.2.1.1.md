# Komicove 0.2.1.1

PT-BR: As preferências do leitor agora permitem escolher entre usar o brilho
manual do Komicove e respeitar o brilho do sistema. O modo e o nível manual
ficam salvos; trocar de modo preserva as outras preferências. O controle
manual fica desativado no modo sistema. No Android, cancelar a prévia
restaura a configuração salva. Os novos textos estão em português e inglês.
O verificador de atualizações reconhece versões com quatro números.

EN: Reader preferences now let you choose between Komicove's manual
brightness and system brightness. The mode and manual level are saved;
switching modes preserves other preferences. Manual controls are disabled
in system mode. On Android, cancelling the preview restores the saved
setting. New labels are available in Portuguese and English. The update
checker recognizes versions with four numeric components.

## Pacotes / Packages

- Windows: Komicove-Setup-0.2.1.1.exe
- Windows portátil / portable: Komicove-Windows-0.2.1.1-portable.zip
- Linux x86_64: Komicove-Linux-0.2.1.1-x86_64.tar.gz
- Flatpak x86_64: Komicove-Linux-0.2.1.1-x86_64.flatpak
- Android: Komicove-Android-0.2.1.1.apk

PT-BR: Os pacotes completos incluem o modelo e o runtime da IA local
existente. O APK universal mantém o identificador com.lucrazy.panel,
versionCode 10722 e mínimo Android 8 (API 26). Atualizar a instalação
existente exige a mesma assinatura. Consulte BUILD_REPORT.md na pasta
dos pacotes para o estado da assinatura e as verificações realizadas.

EN: Complete packages include the existing local AI model and runtime.
The universal APK keeps application ID com.lucrazy.panel, versionCode
10722 and minimum Android 8 (API 26). Updating an existing installation
requires the same signing certificate. See BUILD_REPORT.md in the package
folder for signing status and verification results.
